AWS SECRETS MANAGER SETUP FOR POSTGRESQL + PGVECTOR
=====================================================

1. CREATE SECRET IN AWS SECRETS MANAGER
----------------------------------------
Go to AWS Console > Secrets Manager > Store a new secret
Choose "Credentials for Amazon RDS database"

Enter:
- Username: your postgres username
- Password: your postgres password (or auto-generate)
- Database: your database name (e.g., incidents_db)
- Select the RDS instance

This will auto-generate a secret with format:
{
  "username": "...",
  "password": "...",
  "engine": "postgres",
  "host": "xxx.us-east-1.rds.amazonaws.com",
  "port": 5432,
  "dbname": "...",
  "dbInstanceIdentifier": "..."
}

Save and note the Secret ARN.


2. UPDATE .ENV FILE
-------------------
In your local .env file (or AgentCore environment variables):
DATABASE_URL=arn:aws:secretsmanager:us-east-1:ACCOUNT_ID:secret:SECRET_NAME-XXXXXX

Replace:
- us-east-1 with your AWS region
- ACCOUNT_ID with your 12-digit AWS account ID
- SECRET_NAME with your secret name
- XXXXXX with the random suffix


3. IAM PERMISSIONS
------------------
Add this policy to your AgentCore Runtime execution role:

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "secretsmanager:GetSecretValue"
      ],
      "Resource": "arn:aws:secretsmanager:us-east-1:ACCOUNT_ID:secret:SECRET_NAME-*"
    },
    {
      "Effect": "Allow",
      "Action": [
        "bedrock:InvokeModel",
        "bedrock:InvokeModelWithResponseStream"
      ],
      "Resource": "*"
    }
  ]
}


4. PREPARE RDS DATABASE
-----------------------
Connect to your RDS PostgreSQL instance and run:

CREATE EXTENSION IF NOT EXISTS vector;

Then create the tables by running locally:
python scripts/init_db.py


5. ALTERNATIVE SECRET FORMAT
----------------------------
If creating secret manually, use this JSON:
{
  "username": "postgres",
  "password": "your_password",
  "host": "your-rds-endpoint.rds.amazonaws.com",
  "port": 5432,
  "database": "incidents_db"
}

The application will automatically construct the connection string.


NOTES:
- Ensure RDS is in same VPC/network accessible from AgentCore or publicly accessible
- pgvector extension required for vector similarity search
- Use port 5432 for PostgreSQL
